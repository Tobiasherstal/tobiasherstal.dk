# tobiasherstal.dk

Tobias Herstals hjemmeside: oversigt, om mig, karriere (GRAFCET), projekter, kompetencer og kontakt.

- `index.html` er hele siden (HTML, CSS og JavaScript i én fil).
- `Tobias-Herstal-CV.pdf` er CV'et, som knappen "Hent CV" åbner.
- `CNAME` fortæller GitHub Pages, at siden hører til domænet tobiasherstal.dk.

## Sådan retter du en tekst
1. Åbn `index.html` her på GitHub og tryk på blyanten (Edit).
2. Find teksten med Ctrl+F og ret kun ordene mellem tags – rør ikke `<` `>` og det, der står inde i dem.
3. Tryk "Commit changes". Siden er opdateret efter ca. 1 minut.
